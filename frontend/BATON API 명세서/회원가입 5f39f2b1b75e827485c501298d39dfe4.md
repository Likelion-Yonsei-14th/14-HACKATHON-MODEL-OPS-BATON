# 회원가입

API Path: /api/users
HTTP 메서드: POST
기능 분류: Users
완료 여부: No

# API 설명

💡 새로운 BATON 사용자를 생성하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| email | String | N | 사용자 이메일 |
| password | String | N | 사용자 비밀번호 (최소 8자) |
| name | String | N | 사용자 이름 |
| timezone | String | Y | 사용자 기준 시간대 |
| language | String | Y | 사용 언어 |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | 사용자 id |
| email | String | N | 이메일 |
| name | String | N | 사용자 이름 |
| timezone | String | Y | 사용자 기준 시간대 |
| language | String | Y | 사용 언어 |
| api_key | String | N | 이후 요청의 Bearer 인증에 사용할 API Key |
| created_at | DateTime | N | 생성 시간 |

---

### ⭕Success⭕

**201 Created**

실제 예시

```json
{
  "success": true,
  "data": {
    "id": 1,
    "email": "user@example.com",
    "name": "User A",
    "timezone": "Asia/Seoul",
    "language": "ko",
    "created_at": "2026-08-16T17:00:00+09:00",
    "api_key": "baton_example_api_key"
  },
  "error": null
}
```

---

### ❌Fail❌

**400 Bad Request - 입력값이 올바르지 않을 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "회원가입 입력값이 올바르지 않습니다."
  }
}
```

**409 Conflict - 이미 가입된 이메일일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "EMAIL_ALREADY_EXISTS",
    "message": "이미 가입된 이메일입니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
