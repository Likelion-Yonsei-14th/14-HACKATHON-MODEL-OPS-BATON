# Execution 단일 조회

API Path: /api/executions/{id}
HTTP 메서드: GET
기능 분류: Executions
완료 여부: No

# API 설명

💡 특정 Action 실행 결과와 실패 원인을 상세 조회하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | Execution id |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | Execution id |
| baton_id | Long | N | BATON id |
| classification_id | Long | Y | Classification id |
| result_message_id | Long | Y | 결과 메시지 id |
| action_type | String | N | Action 종류 |
| execution_status | String | N | 실행 상태 |
| executed_at | DateTime | Y | 실행 시간 |
| failure_reason | String | Y | 실패 사유 |
| created_at | DateTime | N | 생성 시간 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "id": 61,
    "baton_id": 12,
    "classification_id": 50,
    "result_message_id": 103,
    "action_type": "SEND_REPLY",
    "execution_status": "SUCCESS",
    "executed_at": "2026-08-17T03:05:00+09:00",
    "failure_reason": null,
    "created_at": "2026-08-17T03:04:55+09:00"
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
