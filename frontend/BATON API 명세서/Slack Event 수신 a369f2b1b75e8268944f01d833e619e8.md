# Slack Event 수신

API Path: /api/webhooks/slack/events
HTTP 메서드: POST
기능 분류: Webhooks
완료 여부: No

# API 설명

💡 Slack Events API의 메시지 이벤트를 수신하고 event_id 중복 검증 후 messages에 저장하는 Webhook API입니다. 신규 메시지가 활성 BATON의 대상 답장인지도 확인합니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| type | String | N | Slack event envelope type |
| event_id | String | Y | Slack event id |
| event | Object | Y | Slack event payload |
| challenge | String | Y | URL verification challenge |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| ok | Boolean | N | 이벤트 수신 여부 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "ok": true
  },
  "error": null
}
```

---

### ❌Fail❌

**400 Bad Request - Slack signature 검증에 실패한 경우**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INVALID_SLACK_SIGNATURE",
    "message": "Slack 요청을 검증할 수 없습니다."
  }
}
```

**500 Internal Server Error - 이벤트 처리 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "SLACK_EVENT_PROCESSING_FAILED",
    "message": "Slack 이벤트 처리 중 오류가 발생했습니다."
  }
}
```
