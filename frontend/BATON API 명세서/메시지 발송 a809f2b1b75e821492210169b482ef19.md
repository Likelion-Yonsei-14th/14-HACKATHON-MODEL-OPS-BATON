# 메시지 발송

API Path: /api/conversations/{conversation_id}/messages
HTTP 메서드: POST
기능 분류: Messages
완료 여부: No

# API 설명

💡 BATON 웹 화면에서 외부 플랫폼 대화로 일반 메시지를 발송하고 messages에 저장하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |
| Content-Type | String | application/json |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| conversation_id | Long | N | 대화 id |

---

# Request Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| content | String | N | 발송할 메시지 내용 |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | 메시지 id |
| external_message_id | String | N | 외부 메시지 id |
| sender_type | String | N | USER |
| content | String | N | 메시지 내용 |
| sent_at | DateTime | N | 발송 시간 |

---

### ⭕Success⭕

**201 Created**

실제 예시

```json
{
  "success": true,
  "data": {
    "id": 101,
    "external_message_id": "1750000000.000100",
    "sender_type": "USER",
    "content": "Can we get the API by March 20?",
    "sent_at": "2026-08-16T23:10:00+09:00"
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
