# Branch 수정

API Path: /api/batons/{baton_id}/branches/{id}
HTTP 메서드: PATCH
기능 분류: Branches
완료 여부: No

# API 설명

💡 AI 생성 또는 수동 생성 Branch의 조건, 결정, 응답, Action을 수정하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |
| Content-Type | String | application/json |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| baton_id | Long | N | BATON id |
| id | Long | N | Branch id |

---

# Request Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| name | String | Y | Branch 이름 |
| description | String | Y | 설명 |
| condition_text | String | Y | 조건 |
| condition_rule_json | Object | Y | 구조화 조건 |
| decision_text | String | Y | 결정 |
| response_text | String | Y | 응답 |
| action_type | String | Y | Action |
| action_config_json | Object | Y | Action 설정 |
| execution_mode | String | Y | 실행 모드 |
| sort_order | Integer | Y | 정렬 순서 |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | Branch id |
| updated_at | DateTime | N | 수정 시간 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "id": 30,
    "updated_at": "2026-08-16T23:11:50+09:00"
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
