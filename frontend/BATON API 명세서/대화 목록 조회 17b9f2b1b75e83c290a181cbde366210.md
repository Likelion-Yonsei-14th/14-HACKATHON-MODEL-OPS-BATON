# 대화 목록 조회

API Path: /api/conversations
HTTP 메서드: GET
기능 분류: Conversations
완료 여부: No

# API 설명

💡 현재 BATON DB에 동기화되어 있는 DM, 채널, 스레드의 대화 메타데이터 목록을 조회하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| platform_connection_id | Long | Y | 특정 플랫폼 연결의 대화만 조회 |
| type | String | Y | DM / CHANNEL / THREAD |
| cursor | String | Y | 페이지네이션 cursor |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| conversations | Array | N | 대화 목록 |
| next_cursor | String | Y | 다음 페이지 cursor |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "conversations": [
      {
        "id": 10,
        "platform_connection_id": 3,
        "external_conversation_id": "D012345",
        "conversation_type": "DM",
        "counterpart_name": "User B",
        "counterpart_timezone": "America/Los_Angeles"
      }
    ],
    "next_cursor": null
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
