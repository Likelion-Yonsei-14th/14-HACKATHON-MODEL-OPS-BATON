# BATON 목록 조회

API Path: /api/batons
HTTP 메서드: GET
기능 분류: Batons
완료 여부: No

# API 설명

💡 현재 사용자의 BATON 목록을 조회하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| status | String | Y | BATON 상태 필터 |
| conversation_id | Long | Y | 대화 id 필터 |
| cursor | String | Y | 페이지네이션 cursor |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| batons | Array | N | BATON 목록 |
| next_cursor | String | Y | 다음 cursor |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "batons": [
      {
        "id": 12,
        "conversation_id": 10,
        "status": "WAITING",
        "auto_send_enabled": true,
        "expires_at": "2026-08-18T09:00:00+09:00"
      }
    ],
    "next_cursor": null
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
