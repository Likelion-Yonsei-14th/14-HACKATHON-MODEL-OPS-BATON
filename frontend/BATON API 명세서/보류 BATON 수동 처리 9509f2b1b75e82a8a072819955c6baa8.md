# 보류 BATON 수동 처리

API Path: /api/batons/{baton_id}/resolve
HTTP 메서드: POST
기능 분류: Executions
완료 여부: No

# API 설명

💡 PENDING_REVIEW 상태 BATON에서 사용자가 특정 Branch를 직접 선택하거나 직접 메시지를 작성하여 처리하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |
| Content-Type | String | application/json |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| baton_id | Long | N | BATON id |

---

# Request Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| resolution_type | String | N | SELECT_BRANCH / MANUAL_REPLY / CANCEL |
| branch_id | Long | Y | 사용자가 선택한 Branch id |
| manual_response | String | Y | 직접 작성한 응답 |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| baton_id | Long | N | BATON id |
| status | String | N | 처리 후 BATON 상태 |
| execution_id | Long | Y | 생성된 Execution id |
| result_message_id | Long | Y | 발송된 메시지 id |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "baton_id": 12,
    "status": "COMPLETED",
    "execution_id": 62,
    "result_message_id": 104
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
