# Execution 목록 조회

API Path: /api/batons/{baton_id}/executions
HTTP 메서드: GET
기능 분류: Executions
완료 여부: No

# API 설명

💡 특정 BATON에서 발생한 자동 발송, 사용자 확인 요청 등의 실행 이력을 조회하는 API입니다. 실행 생성은 서버 내부에서 처리합니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| baton_id | Long | N | BATON id |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| executions | Array | N | 실행 목록 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "executions": [
      {
        "id": 61,
        "classification_id": 50,
        "result_message_id": 103,
        "action_type": "SEND_REPLY",
        "execution_status": "SUCCESS",
        "executed_at": "2026-08-17T03:05:00+09:00",
        "failure_reason": null
      }
    ]
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
