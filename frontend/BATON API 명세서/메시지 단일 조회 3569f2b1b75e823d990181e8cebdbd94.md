# 메시지 단일 조회

API Path: /api/messages/{id}
HTTP 메서드: GET
기능 분류: Messages
완료 여부: No

# API 설명

💡 특정 메시지의 전체 내용을 조회하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | 메시지 id |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | 메시지 id |
| conversation_id | Long | N | 대화 id |
| external_message_id | String | N | 외부 메시지 id |
| sender_external_id | String | N | 발신자 외부 id |
| sender_type | String | N | USER / COUNTERPART / BATON |
| content | String | N | 메시지 내용 |
| original_language | String | Y | 원문 언어 |
| is_baton_generated | Boolean | N | BATON 생성 여부 |
| sent_at | DateTime | N | 발송 시간 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "id": 101,
    "conversation_id": 10,
    "external_message_id": "1750000000.000100",
    "sender_external_id": "U123",
    "sender_type": "USER",
    "content": "Can we get the API by March 20?",
    "original_language": "en",
    "is_baton_generated": false,
    "sent_at": "2026-08-16T23:10:00+09:00"
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
