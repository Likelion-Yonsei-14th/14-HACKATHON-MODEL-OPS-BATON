# 대화 단일 조회

API Path: /api/conversations/{id}
HTTP 메서드: GET
기능 분류: Conversations
완료 여부: No

# API 설명

💡 특정 대화의 메타데이터를 조회하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | 대화 id |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | 대화 id |
| platform_connection_id | Long | N | 플랫폼 연결 id |
| external_conversation_id | String | N | 외부 대화 id |
| external_thread_id | String | Y | 외부 thread id |
| conversation_type | String | N | 대화 유형 |
| title | String | Y | 대화 제목 |
| counterpart_external_id | String | Y | 상대 외부 사용자 id |
| counterpart_name | String | Y | 상대 이름 |
| counterpart_timezone | String | Y | 상대 시간대 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "id": 10,
    "platform_connection_id": 3,
    "external_conversation_id": "D012345",
    "external_thread_id": null,
    "conversation_type": "DM",
    "title": null,
    "counterpart_external_id": "U987654",
    "counterpart_name": "User B",
    "counterpart_timezone": "America/Los_Angeles"
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
