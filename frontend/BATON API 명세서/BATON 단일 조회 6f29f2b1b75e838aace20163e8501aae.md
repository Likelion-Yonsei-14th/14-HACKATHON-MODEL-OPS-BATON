# BATON 단일 조회

API Path: /api/batons/{id}
HTTP 메서드: GET
기능 분류: Batons
완료 여부: No

# API 설명

💡 특정 BATON의 상태와 주요 정보를 조회하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | BATON id |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | BATON id |
| conversation_id | Long | N | 대화 id |
| trigger_message_id | Long | N | 원본 메시지 id |
| reply_message_id | Long | Y | 상대 답장 메시지 id |
| status | String | N | BATON 상태 |
| auto_send_enabled | Boolean | N | 자동 발송 여부 |
| expires_at | DateTime | Y | 만료 시간 |
| activated_at | DateTime | Y | 활성화 시간 |
| completed_at | DateTime | Y | 완료 시간 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "id": 12,
    "conversation_id": 10,
    "trigger_message_id": 101,
    "reply_message_id": null,
    "status": "WAITING",
    "auto_send_enabled": true,
    "expires_at": "2026-08-18T09:00:00+09:00",
    "activated_at": "2026-08-16T23:12:00+09:00",
    "completed_at": null
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
