## 현재 구현 기준

PR #5 이후 구현을 기준으로 정리했습니다.

- 모든 외부 API 경로는 `/api` prefix를 사용합니다.
- 인증이 필요한 요청은 `Authorization: Bearer <api_key>`를 사용합니다.
- 성공 응답은 `{success: true, data, error: null}`, 실패 응답은 `{success: false, data: null, error: {code, message}}` 형식입니다.
