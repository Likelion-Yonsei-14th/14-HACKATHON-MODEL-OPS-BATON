# 홈 KPI 조회

API Path: /api/dashboard/metrics
HTTP 메서드: GET
기능 분류: View
완료 여부: No

# API 설명

💡 Waiting Time Saved, Round Trips Skipped, Offline Completed 등 홈 화면 핵심 효과 지표를 조회하는 API입니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| period | String | Y | WEEK / MONTH, 기본 WEEK |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| waiting_time_saved_minutes | Long | N | 절약된 대기 시간 추정치 |
| round_trips_skipped | Integer | N | 줄인 메시지 왕복 수 |
| completed_while_offline | Integer | N | 오프라인 동안 완료된 BATON 수 |
| active_batons | Integer | N | 현재 활성 BATON 수 |
| needs_attention | Integer | N | 사용자 확인 필요 BATON 수 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "waiting_time_saved_minutes": 840,
    "round_trips_skipped": 3,
    "completed_while_offline": 4,
    "active_batons": 5,
    "needs_attention": 2
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
