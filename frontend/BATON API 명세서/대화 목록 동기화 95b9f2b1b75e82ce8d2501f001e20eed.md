# 대화 목록 동기화

API Path: /api/platform-connections/{connection_id}/conversations/sync
HTTP 메서드: POST
기능 분류: Platform Connections
완료 여부: No

# API 설명

💡 특정 Slack 연결에서 BATON이 접근 가능한 대화 목록의 메타데이터만 동기화하는 API입니다. 메시지 히스토리는 가져오지 않습니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |
| Content-Type | String | application/json |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| connection_id | Long | N | 플랫폼 연결 id |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| platform_connection_id | Long | N | 플랫폼 연결 id |
| created_count | Integer | N | 새로 저장된 대화 수 |
| updated_count | Integer | N | 갱신된 대화 수 |
| last_synced_at | DateTime | N | 동기화 완료 시간 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "platform_connection_id": 3,
    "created_count": 3,
    "updated_count": 5,
    "last_synced_at": "2026-08-16T17:00:00+09:00"
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
