# 플랫폼 연결 단일 조회

API Path: /api/platform-connections/{id}
HTTP 메서드: GET
기능 분류: Platform Connections
완료 여부: No

# API 설명

💡 특정 외부 플랫폼 연결의 워크스페이스 정보와 연결 상태를 조회하는 API입니다. 토큰 원문은 응답하지 않습니다.

구현 응답 형식: 성공은 `{success, data, error: null}`, 실패는 `{success: false, data: null, error: {code, message}}` wrapper를 사용합니다.

---

# Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | Bearer &lt;api_key&gt; |

---

# Request Parameter

| name | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | 플랫폼 연결 id |

---

# Response Body

| field | type | Nullable | Description |
| --- | --- | --- | --- |
| id | Long | N | 연결 id |
| platform_type | String | N | 플랫폼 종류 |
| workspace_id | String | N | 워크스페이스 id |
| workspace_name | String | Y | 워크스페이스 이름 |
| connection_status | String | N | 연결 상태 |
| token_expires_at | DateTime | Y | 토큰 만료 시간 |
| last_synced_at | DateTime | Y | 마지막 동기화 시간 |

---

### ⭕Success⭕

**200 OK**

실제 예시

```json
{
  "success": true,
  "data": {
    "id": 3,
    "platform_type": "SLACK",
    "workspace_id": "T012345",
    "workspace_name": "BATON Test",
    "connection_status": "CONNECTED",
    "token_expires_at": null,
    "last_synced_at": "2026-08-16T16:20:00+09:00"
  },
  "error": null
}
```

---

### ❌Fail❌

**401 Unauthorized - 인증되지 않은 사용자일 때**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "로그인이 필요합니다."
  }
}
```

**500 Internal Server Error - 서버 오류 시**

실제 예시

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부 오류가 발생했습니다."
  }
}
```
